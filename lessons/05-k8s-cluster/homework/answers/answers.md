אנלוגיה | מה הוא עושה במשפט אחד | איפה הוא רץ (הנהלה / כל node) | רכיב
API server |	הנהלה | מקבל את הבקשות | המלצר שמקבל את ההזמנות 		
etcd			| רשימה של ההזמנה הקבועה | שומר וזוכר את ההגדרות של ה-cluster | הנהלה
scheduler	|	מנהל המשמרת - שקובע איפה כל עובד יהיה | מחליט באיזה NODE כל POD חדש ירוץ | רץ בהנהלה 
controller manager	|	כמו מפקח על עובדי ותפוקת המטבח | בודק שהמצב של ה-cluster תואם למצב הנדרש | בהנהלה	
kubelet			| אחראי עמדת בישול שמבצע את ההוראות לעמדה הזו | אחראי שה-PODS שהוקצו ל-NODE ירוצו כראוי | בכל NODE
container runtime	| כמו הטבח שבפועל מבשל |		מפעיל בפועל את ה-CONTAINERS | כל NODE  
kube-proxy	| אחראי שמנתב הזמנות לעמדות המתאימות | מנתב בקשות וביצועים ל-PODS שיבצעו אותם - ומתאימים לביצוע הדבר - גם אם הם ב- NODES אחרים | בכל NODE 
coredns | כמו ספר טלפונים של המטבח - לכל עמדה - שרות את המס טלפון | ממיר בין שמות SERVICES שרושמים לכתובות ה-IP שלהם | בכל POD -NODE
