
| רכיב | איפה הוא רץ (הנהלה / כל Node) | מה הוא עושה במשפט אחד | אנלוגיה |
|---|---|---|---|
| API Server | הנהלה | מקבל את הבקשות | המלצר שמקבל את ההזמנות |
| etcd | הנהלה | שומר וזוכר את ההגדרות והמצב של ה־Cluster | רשימה קבועה של ההזמנות |
| Scheduler | הנהלה | מחליט באיזה Node כל Pod חדש ירוץ | מנהל המשמרת שקובע איפה כל עובד יהיה |
| Controller Manager | הנהלה | בודק שהמצב של ה־Cluster תואם למצב הנדרש | מפקח על העובדים ועל תפוקת המטבח |
| kubelet | בכל Node | אחראי שה־Pods שהוקצו ל־Node ירוצו כראוי | אחראי עמדת בישול שמבצע את ההוראות לעמדה הזו |
| Container Runtime | בכל Node | מפעיל בפועל את ה־Containers | הטבח שבפועל מבשל |
| kube-proxy | בכל Node בדרך כלל | מגדיר כללי ניתוב לבקשות אל ה־Pods המתאימים, גם אם הם נמצאים ב־Nodes אחרים | אחראי שמנתב הזמנות לעמדות המתאימות |
| CoreDNS | כ־Pods ב־Cluster, בדרך כלל על Worker Nodes | ממיר שמות של Services לכתובות ה־IP שלהם | ספר הטלפונים של המטבח, שבו לכל שירות יש מספר טלפון |
